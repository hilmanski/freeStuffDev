All 40+ tools are completely free — no account, no watermark, no premium tier.

Every operation runs client-side in the browser (Canvas + WebAssembly), so images are never uploaded to a server; an automated test suite asserts that no upload or external-origin request ever happens. Covers JPG/PNG/WebP/AVIF conversion (40+ pairs, plus HEIC import from iPhone photos), compression with a live quality slider, resizing, cropping, filters, EXIF cleanup and batch processing with ZIP download.
