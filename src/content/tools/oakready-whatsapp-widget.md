This free builder needs no Oakready account or API key: enter your public WhatsApp number, choose an icon-only or labelled button, pick a bottom corner, set optional opening hours, then preview and copy the embed code.
Or copy a chat link for a button you already have (opening hours don't apply to the link).
Clicking opens WhatsApp or WhatsApp Web; conversations happen there, not in an on-site inbox.
You need an active WhatsApp or WhatsApp Business number, and it will be visible in the code and link.
