Free to self-host for personal, educational, research, and internal team use
Visual browser recorder with noVNC live session
Playwright Chromium runner with per-step screenshots and trace viewer
Cron schedules for checks and suites
Environment variables for reusable test data
Telegram and Slack alerts for failed and recovered runs
Export recorded checks to native Playwright .spec.ts files
